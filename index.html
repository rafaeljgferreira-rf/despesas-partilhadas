Configuração da sincronização

Para partilhar despesas entre dois utilizadores e todos os seus dispositivos, esta aplicação usa uma base de dados sbClient.

A configuração fica guardada neste dispositivo. Terás de a introduzir também nos outros dispositivos, ou abrir a aplicação já configurada a partir de um alojamento comum.

Como obter estes dados?
  1. Cria um projeto gratuito em supabase.com.
  2. Em Project Settings → API, copia Project URL e a chave anon/public.
  3. Executa o SQL fornecido no ficheiro configuracao_sbClient.sql no SQL Editor do sbClient.
Aceder à aplicação

Cada pessoa deve usar a sua própria conta. Assim, a aplicação identifica quem registou cada despesa.

Partilhar com a outra pessoa

Uma pessoa cria o espaço partilhado e envia o código à outra. A segunda pessoa escolhe “Entrar com código”.
